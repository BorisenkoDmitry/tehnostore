# TEXNO STORE — заметки проекта

## 2026-11-07 — жизненный цикл условий каталога при навигации

Источник: пользователь показал сочетание поиска Honor, выбранного Redmi 13C, памяти 128 ГБ и старого диапазона 395–6990 RUB; попросил исключить нелогичное наслоение условий.

Принята консервативная детерминированная политика: любой явный выбор узла левого дерева, включая повторный выбор текущего узла/«Все [бренд]», начинает новую выборку. Поиск и его черновик, атрибуты, цена и страница сбрасываются; сортировка сохраняется. Ценовой диапазон берётся из свежих серверных facets новой категории и не записывается в URL как пользовательское ограничение. Общие атрибуты и ранее введённая цена между узлами намеренно не переносятся: это исключает неоднозначное наследование условий. «Сбросить» в панели очищает условия текущей категории; «Сбросить всё», «Все товары» и empty-state «Показать все товары» возвращают общий каталог, сохраняя сортировку.

Внутри той же категории поиск/цвет/цена остаются осмысленным AND, автоматического сброса при нуле результатов нет. Back/Forward и reload восстанавливают URL, поля и chips. Навигация синхронно отменяет search debounce 300 ms и price timer 450 ms; callbacks привязаны к версии контекста. Устаревшие ответы проверяют версию запроса, pathname и URL перед изменением выдачи/URL. До прихода facets нового контекста старые атрибуты/цена неинтерактивны; обычные изменения внутри текущего контекста доступны.

Товарная БД и импорт в этой правке не изменялись. Область изменений: catalog provider, catalog-data, catalog panel и store template. Файлы страницы товара/Swiper другого чата не менялись. Проверки: TypeScript PASS, scoped ESLint 0 errors (2 прежних предупреждения effect loading), изолированная production-сборка PASS без остановки dev и 25 headless browser checks PASS, включая исходный пример, phone/accessory переходы, pending search+price, delayed-response race, history/reload, reset scopes и обычные комбинации условий. Отчёт: `../output/catalog-import/catalog-lifecycle-verification.json`; build log: `catalog-lifecycle-build.log`; скриншот исправленного примера: `../output/playwright/catalog-lifecycle-redmi-fixed.png`.

Текущий статус на 2026-11-07: локальный импорт выполнен и проверен — 1 172 товара / 1 244 варианта. Фильтры сокращены по последнему решению пользователя, все 50 цветов показываются кружками. Актуальная реализация и ограничения описаны в последнем разделе; ранние записи о будущем импорте являются историей решений.
